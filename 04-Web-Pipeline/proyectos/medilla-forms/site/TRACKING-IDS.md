## Placeholder Tracking IDs

Replace these in `index.html`, `gracias.html`, and conversion scripts:

| ID | Placeholder | Where to get it |
|---|---|---|
| GA4 | `G-XXXXXXXXXX` | analytics.google.com → Admin → Data Streams → Measurement ID |
| Meta Pixel | `PIXEL_ID_PLACEHOLDER` | business.facebook.com → Events Manager → Pixels → Pixel ID |
| Google Ads Conversion | `AW-CONVERSION_ID/thank-you` | ads.google.com → Tools → Conversions → Conversion Action ID |
| Google Search Console | `googlePLACEHOLDER.html` | search.google.com/search-console → Add Property → HTML verification file |
